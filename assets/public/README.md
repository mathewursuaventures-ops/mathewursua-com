# Public asset downloads

This directory holds stable, directly downloadable public files (letters, headshots, documents).
Files are **not linked from the website navigation or visible HTML pages**.
Approved assets may be explicitly included in the root `/sitemap.xml` for search-engine discovery.
Publishing here does **not** make files private. Do not store sensitive documents in this directory.

Rules:
- Use lowercase descriptive hyphenated filenames with a date for historical documents.
- Keep original published files at the same path; publish revised editions at new paths.
- Preserve existing website pages and metadata when adding assets.
- Include indexable files in the root sitemap and keep the preflight allowlist in sync.
- Never remove a long-lived URL without a migration and external reference audit.
